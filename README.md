# GRAPHICX

Sistema de gestão da GRAPHICX: pedidos, aprovação de artes, produção (PCP), estoque, financeiro, NF-e, dashboard para TV e integração com marketplaces (Shopee, Magalu, TikTok Shop).

**Stack:** Next.js · React · TypeScript · Tailwind CSS · Supabase · Vercel
